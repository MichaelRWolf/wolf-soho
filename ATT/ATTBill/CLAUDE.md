# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## File Naming

Bills in this directory use `ATTBill_0230_YYYY-MM-DD.pdf`, where the date is the bill's "Issue Date" (ISO 8601). AT&T bills issue on the 24th, so the day is `24`, for example `ATTBill_0230_2026-08-24.pdf`.

- Read the Issue Date from the PDF to confirm the day; do not assume it.
- Dispute docs in `ATT/2026_dispute/` cite bills by these filenames. Update those references when renaming a bill.
